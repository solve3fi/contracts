# Solve3 Contracts Wiki

Durable project knowledge, kept as Markdown in Git. Existing documents are linked where they live rather than copied.

Before adding something here, ask: will an agent working on this project a month from now need this? If it is mainly for the next work session it belongs in [the handoff](../agent/HANDOFF.md); what happened in a session belongs in the daily log; questions for a human belong in [BLOCKERS](../agent/BLOCKERS.md); approved decisions belong in [DECISIONS](../agent/DECISIONS.md).
